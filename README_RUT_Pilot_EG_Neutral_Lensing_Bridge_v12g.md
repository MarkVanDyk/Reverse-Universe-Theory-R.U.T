This archive documents a reduced, falsifiable growth-lensing test motivated by Reverse Universe Theory (RUT). It treats RUT as motivation for a frozen phenomenological bridge model, not as a confirmed replacement for LambdaCDM.

The main tested form is:

mu(a) = 1 + mu0 B(a), Sigma(a) = 1

with

B(a) = 1/2 [1 + tanh((a - a_t)/Delta a)]

and frozen values:

- a_t = 0.55
- Delta a = 0.08
- mu0 approx 0.172759
- lambda_Sigma = 0
